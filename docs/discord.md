# Discord の動線

Botや外部ツールは使わず、Discord の標準機能（フォーラムチャンネル・タグ・ロール・メンション）だけで回す。

**基本の考え方: 動画1本 = フォーラムの投稿1つ。工程はタグで表し、受け渡しはメンションで伝える。**

## チャンネル構成

```
📁 GSHISTORY
├── 📌 はじめに        … ルール・役割・Driveのリンク（ピン留め）
├── 🎬 制作            … フォーラム。動画1本につき投稿1つ ← メイン
├── 🔗 参考動画        … 伸びてるショートを貼るだけ（ネタ・演出の参考）
└── 💬 連絡            … 雑談・ネタ会議の日程など
```

## ロール

| ロール | 付ける人 | 使いどころ |
|---|---|---|
| `@アイデア` | 発起人・ゆうへいさん | ネタ会議の呼び出し、台本の事実確認依頼 |
| `@素材` | 発起人 | 台本OK・素材の修正依頼 |
| `@編集` | 麻生さん | 素材そろった・修正依頼 |

名前で直接メンションしてもOK。ロールは担当が増えたときのため。

## 🎬 制作（フォーラム）の設定

**タグ**（フォーラムの設定 → タグ。「タグ必須」をオン）

| タグ | 意味 | 次に動く人 |
|---|---|---|
| 💡アイデア | ネタだけある | ネタ会議で採用を決める |
| ✅採用 | 作ると決めた | 発起人（台本） |
| 📝台本 | 台本を書いている／確認待ち | 発起人 → ゆうへいさん（事実確認） |
| 🎨素材 | 素材を作っている | 発起人 |
| ✂️編集 | 編集中 | 麻生さん |
| 👀確認 | 3人で見る | 3人 |
| 📤投稿済み | 投稿した | 1週間後に振り返り |
| 🗄️ボツ | やめた | — |

- **タグは常に1つだけ**付ける。工程が進んだら、渡す人がタグを付け替える。
- フォーラム一覧をタグで絞り込めば「今、編集待ちは何本？」がすぐ分かる。
- 投稿済みになって振り返りも書いたら、投稿を **クローズ** する（一覧から消えてスッキリする）。

**投稿ガイドライン**（フォーラムの設定 → 投稿ガイドライン に貼る）

```
タイトルは「番号 タイトル」（例: 007 信長の草履あたため、実は…）
本文はピン留めのテンプレをコピー。タグは1つだけ付ける。
```

## 投稿（スレッド）の書き方

### タイトル

`007 信長の草履あたため、実は…`（番号は3桁の通し番号）

### 最初のメッセージ（提案者が書く）

```
🪝 最初の一言:
🎯 オチ:
📚 ネタ元:
🗓️ 投稿予定日: （採用されたら入れる）
📁 Drive: （採用されたら入れる）
```

台本はこのスレッドに貼る（長ければ Google ドキュメントにしてリンクを貼る）。構成の型は [format.md](format.md)。

### 受け渡しのメッセージ（コピペ用）

タグを付け替えてから、スレッド内で次の人にメンションする。

| いつ | 誰が | メッセージ |
|---|---|---|
| 台本ができた | 発起人 | `@ゆうへい 台本できた。事実確認お願い 🙏` |
| 事実確認OK | ゆうへいさん | `確認OK ✅`（直すところがあれば「〇〇は△△説が有力」など） |
| 素材がそろった | 発起人 | `@麻生 素材そろった！ Drive: <リンク> / 雰囲気: 〇〇 / 強調したいところ: 〇〇` |
| 編集v1ができた | 麻生さん | `@アイデア @素材 v1できた → <リンク> 確認お願い` |
| 修正依頼 | 誰でも | `0:12 テロップ「1560年」→「1560年（桶狭間）」に`（秒数・何を・どうするの3点） |
| 確認OK | 3人それぞれ | 動画のメッセージに ✅ リアクション（3つそろったら投稿へ） |
| 投稿した | 投稿担当 | `投稿しました 📤 YT: <URL> / TT: <URL> / IG: <URL>` |
| 1週間後 | 誰でも | `📊 YT 〇回 / TT 〇回 / IG 〇回。気づき: 〇〇` |

## 1週間の回し方

| 曜日 | やること | 場所 |
|---|---|---|
| 月 | ネタ会議（15分）。💡アイデア の投稿を見て、作るものを ✅採用 に変える | ボイスチャンネル or 💬連絡 |
| 火 | 台本 → ゆうへいさんが事実確認 | 各スレッド |
| 水〜木 | 素材作成 → 麻生さんにメンション | 各スレッド |
| 金〜土 | 編集 v1 | 各スレッド |
| 日 | 3人で確認 → 修正 → 投稿 | 各スレッド |

ネタ会議の時間をDiscordの **イベント** に毎週で登録しておくと、通知が来るので忘れない。

## 📌 はじめに に置くもの（ピン留め）

```
【歴史ショート】約60秒・縦動画で YouTube / TikTok / Instagram に投稿

■ 担当
アイデア: 発起人・ゆうへいさん
台本・素材: 発起人（事実確認: ゆうへいさん）
編集: 麻生さん

■ 流れ
💡アイデア → ✅採用 → 📝台本 → 🎨素材 → ✂️編集 → 👀確認 → 📤投稿済み
動画1本 = 🎬制作 の投稿1つ。進んだらタグを付け替えて、次の人にメンション。

■ リンク
Drive: <共有フォルダのURL>
```

> パスワードや2段階認証のコードは Discord に書かない（スクショも含む）。アカウントの共有方法は [README](../README.md) を参照。
