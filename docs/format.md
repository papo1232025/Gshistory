# 動画フォーマット

## 60秒の構成テンプレ

| 時間 | パート | 中身 | ナレーション文字数の目安 |
|---|---|---|---|
| 0〜3秒 | フック | 「え？」と思わせる一言。結論・意外な事実・問いかけ | 〜20字 |
| 3〜15秒 | 前提 | いつ・どこ・誰の話か。最低限の背景だけ | 〜70字 |
| 15〜45秒 | 本題 | 出来事の流れ。3〜4シーンに分ける | 〜170字 |
| 45〜55秒 | 意外な展開 | 「実はこの後…」などの山場 | 〜60字 |
| 55〜60秒 | オチ | 一言でまとめる／冒頭につながる締め（ループ視聴を狙う） | 〜30字 |

- 日本語ナレーションは **1秒 ≒ 5〜6字**。60秒なら合計 **300〜350字** に収める。
- 1シーンは **3〜5秒** で画を切り替える（画面が止まると離脱されやすい）。
- 参考動画の型（テンポ、テロップの出し方、BGMの雰囲気など）は3人で一度見て、気づいた点をここに追記する。

## 書き出し仕様（3つ共通で1本作る）

| 項目 | 設定 |
|---|---|
| 解像度 | 1080 × 1920（縦 9:16） |
| フレームレート | 30fps |
| 形式 | MP4（H.264 / AAC） |
| 尺 | 60秒前後（3つのSNSすべてで問題なく投稿できる長さ） |

### テロップの安全エリア

各アプリのUI（いいねボタン・キャプション・アカウント名）で隠れないように、文字は次の範囲に置く。

- 上: 端から約 **250px** はあける
- 下: 端から約 **450px** はあける（キャプション・ボタンが重なる）
- 右: 端から約 **150px** はあける（いいね・コメントボタン）

### SNSごとの注意

- **ウォーターマークなしの元ファイルを各SNSに直接アップする。** TikTokで保存した動画（ロゴ入り）をInstagramやYouTubeに上げると、おすすめに載りにくくなる。
- BGMは各SNSのライブラリから付けるか、商用利用OKの音源を `00_共通素材/` に集めて使う。市販曲を編集で入れると、プラットフォームによってミュート・ブロックされることがある。

## 歴史ネタならではのルール

- **出典を台本に必ず書く**（本・Webページ名）。諸説ある話は「〜という説がある」と言う。
- 有名な逸話でも後世の創作のことが多い（例: 逸話・名言系）。ゆうへいさんの事実確認で引っかかったら、「実は創作だった」というネタに変えるのもアリ。
- 画像の権利:
  - 古い絵画・浮世絵・古地図などはパブリックドメインのものが多いが、**撮影した人／所蔵館の利用条件**を確認する（Wikimedia Commons はライセンス表示がある）。
  - 自作イラストやAI生成画像を使う場合、写実的な人物・出来事を描いた画像は、YouTube・TikTokの **「AI生成／改変コンテンツ」の表示設定** をオンにする。
- 特定の民族・宗教・国をおとしめる表現、戦争・虐殺を茶化す表現は避ける（収益化停止・削除の対象になりやすい）。
