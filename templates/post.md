# 投稿チェックリスト

## 投稿前

- [ ] 3人のOKが出ている
- [ ] `04_完成/{番号}_final.mp4`（1080×1920 / ロゴなし）を使う
- [ ] テロップが安全エリア内にあり、誤字がない
- [ ] 年号・人名を最終確認した
- [ ] AI生成の写実的な画像を使っている場合、各SNSでAI表示をオンにする

## キャプション

```
{タイトル／一言フック}

{本文 1〜2行。動画の補足や「続きはコメントで」など}

#歴史 #日本史 #{人物名} #{時代} #shorts
```

| SNS | タイトル・キャプションのポイント |
|---|---|
| YouTube Shorts | タイトル（100字以内）に人物名を入れる。説明欄に出典を書く |
| TikTok | 冒頭の一文で興味を引く。ハッシュタグは3〜5個 |
| Instagram Reels | カバー画像を選ぶ（グリッドで見えるので文字入りが良い）。「フィードにもシェア」をオン |

## 投稿後

- [ ] 3つのURLを管理表に記入
- [ ] 最初の1時間はコメントに返信する
- [ ] 1週間後に再生数・平均視聴時間（維持率）を管理表に記入
